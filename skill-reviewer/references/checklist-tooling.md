# D. 工具使用层 Checklist

工具使用层审查 SKILL 中对外部工具、命令、脚本的使用是否安全可靠。

如果 SKILL 不涉及任何外部工具或脚本调用，所有条目标记为 N/A，维度 D 不产生 findings。

---

## D1: 外部依赖有 Prerequisites 说明

**检查位置**：SKILL.md 及 references/ 中使用工具/命令的位置
**通过条件**：每个外部依赖（如 python3、node、特定 CLI 工具）在被使用前有安装检查步骤或 Prerequisites 章节，列出工具名、检查命令、安装方法
**不通过 → Critical**（主流程依赖无说明），**Major**（可选工具无说明）
**改进建议**：添加 Prerequisites 章节，格式为：工具名 + 检查命令（如 `python3 --version`）+ 各平台安装方法

---

## D2: 命令示例可直接运行

**检查位置**：所有 bash/shell 代码块
**通过条件**：命令中的占位符（如 `<your-path>`）有明确说明；命令语法正确；无未声明的变量引用；示例可被用户直接复制并修改后运行
**不通过 → Major**
**改进建议**：将 `<placeholder>` 替换为具体示例值，或在旁边添加注释说明如何获取该值

---

## D3: 关键工具调用有失败处理路径

**检查位置**：工具调用步骤
**通过条件**：主流程中的关键工具调用说明了失败时的处理方式，如"如果命令返回非 0，报告错误并停止"
**不通过 → Major**
**改进建议**：在关键命令后添加 "If the command fails, [specific action]"

---

## D4: 脚本参数有清晰说明

**检查位置**：scripts/ 目录文件说明 + SKILL.md 中的脚本调用处
**通过条件**：每个脚本的必填参数和可选参数有说明，包含参数含义、类型和示例值
**不通过 → Major**
**改进建议**：在命令示例旁添加参数说明，格式为：参数名 — 含义 — 示例值

---

## D5: 无未声明的环境依赖

**检查位置**：全文
**通过条件**：不隐式依赖特定环境变量、配置文件或网络访问，或已明确声明这些依赖及获取方式
**不通过 → Major**
**改进建议**：列出所有环境依赖（环境变量名、配置文件路径），并说明如何设置

---

## D6: 路径使用相对路径

**检查位置**：所有文件路径引用（命令、脚本、SKILL.md 正文）
**通过条件**：路径引用使用相对路径（如 `references/xxx.md`），不硬编码用户机器上的绝对路径（如 `/Users/xxx/...`）
**不通过 → Major**（出现在命令或脚本中），**Minor**（仅出现在说明文字中）
**改进建议**：将绝对路径改为基于 SKILL 目录的相对路径
